`catalog.json` 保存原始链接、资料核对日期、编辑归纳和建议。价格缺乏可靠来源的条目，在前端明确显示待核实或分景区售票；既有演示价格并未被重新认证。天坛的票价来源发表于2023年，界面明确提示重新核对。游览时长是编辑建议，票务与临时开放规则以官网最新公告为准。

`../scripts/prepare-content.py` 生成可审查清单、前端清单副本和本地示意封面。清单是人工核对后的编辑结果，并不是未经审核的抓取数据。

`../scripts/import-content.py` 使用参数化 SQL、事务及同名去重导入本地 MySQL。运行前通过环境变量提供 MYSQL_PASSWORD，MYSQL_PORT 默认3307。导入前将涉及的原记录保存为本目录的 `backup-content-*.json`；不删除既有用户内容。重复导入已验证保持9个景点、9篇帖子，其中5篇为本批次编辑内容。

详情页的来源提示位于 `SourceNotice.vue`。前端资料副本在 `zhituxing-ui/src/data/catalog.json`，修改清单后需保持副本同步。此次没有重建 AI 向量知识库，前端新增导览不代表模型已检索这些资料。

验证：前端 TypeScript/Vite 构建通过；本地 API 返回新记录；浏览器验证目的地与攻略详情、来源超链接、无评分提示和本地封面正常显示。
